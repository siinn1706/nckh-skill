# Verdict, locator and freshness checks

Identity: origin/DOI/version/status/access. Support: observed content and claim scope.
Quote: exact original text/context and page/line/section/table/figure, visually checked
after OCR. Statistic: value, unit, denominator, population, time and transformation.
Record each separately; a pass in one is not a pass in another.

Supported -> retain the observed certainty/scope. Contradicted -> correct or report
the conflict with counterevidence. Insufficient -> narrow to the observed boundary.
Unverified -> label uncertainty or stop the factual claim. Do not accept a claim
because its DOI exists. A supplied model verdict is not independent scientific proof.

Freshness triggers: correction/retraction notice, source edition/version, changing
task scope, venue/year/track/article type, ranking issuer/category/year or stale access.
Recheck affected dependencies and preserve prior receipts/immutable sources.
