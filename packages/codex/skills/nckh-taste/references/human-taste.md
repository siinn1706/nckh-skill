# Human taste evaluation

Before review freeze genre/locale, sample rights, reviewer roles, coverage, rubric,
quality threshold, holdout split and allowed budget/development rounds. Store the
actual corpus, labels and reviewer identity in an authorized private location.

Blind samples use document/author/topic/claim-family separation and enforce label
isolation from the writer when the host can. If isolation is absent report nonblind;
if a holdout is exposed move it to development and retain lineage.

Evaluate VI rhythm/specificity/register separately from EN fidelity/domain usage.
Human edit time and native preferences are observed data, not model estimates.
No samples/reviewer/threshold means pending, never fabricated human approval.
