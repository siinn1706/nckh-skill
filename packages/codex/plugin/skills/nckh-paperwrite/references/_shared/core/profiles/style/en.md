# English style by task

Prioritize precise referents, controlled certainty, consistent task terminology and
readable reasoning. Scientific reporting follows the selected venue/year/track/article
type, not a universal IMRaD template. Preserve evidence, methods/results distinction,
units/denominators/population/time and limitations.

Translation preserves negation, modality, causal scope and meaningful ambiguity.
A VI taste rubric is not mechanically translated into an English one.
Literary/general/marketing genres keep their own register and objective.

Language polish and domain fidelity are separate acceptance dimensions. Model
critique is advisory; human/domain review is required for claimed quality acceptance.
