# UCI Bank Marketing snapshot rights

> Owned package metadata: this file is an authored rights record and is not a
> verbatim copy of the upstream Creative Commons license.

The packaged JSONL contains the first ten data rows from the official UCI
Bank Marketing `bank.csv`, parsed with its stated semicolon delimiter. The
official dataset page identifies CC BY 4.0 and DOI `10.24432/C5K306`; retain
that attribution and DOI when using the sample. The outer and nested archive
hashes remain lineage evidence; the ZIP files are not packaged.

This is a bounded development sample, not a representative population or a
causal experiment. The `duration` field is post-contact and can leak the
target in prospective prediction. The sample transformation is retained as
lineage.
