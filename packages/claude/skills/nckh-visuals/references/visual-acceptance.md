# Visual gate matrix

Chart: actual dataset/provenance, transformations, units/denominators, source-to-mark map.
Mechanism: source for each node/arrow, direction/uncertainty, inferred edges labeled.
Research illustration: illustrative/non-evidentiary label and provenance, no measurement claims; branding/logo/banner/generic artwork is outside this route.

Derived/computational/simulation charts bind actual code, model/version/parameters,
source/transform/output and completed run hashes. Label them not observed measurements;
missing run/uncertainty/labels is pending. Purpose and source-to-mark preflight are
independent from engine receipt integrity and scientific/native/human acceptance.
Slides: narrative, native editable elements, typography/layout, alt text and licenses.

Required independent checks: source truth, rights, native editability, render/layout,
accessibility and scientific/domain meaning. Use actual opener/renderer evidence for
the selected engine; a PNG preview or .pptx extension does not establish editability.

QA receipt binds source/data/artifact/render/manifest hashes, viewer/font versions,
run ID and evidence references. Changes invalidate affected checks before handoff.
An empty/unverified effective engine binding is unavailable. The bundled
native-documents default remains unavailable/null; a separately supplied trusted
project/task/host binding may enable only its verified SVG rendering capability.
An invalid explicit binding stops without fallback. Receipt hashes and successful
process fields establish integrity/matching only; the controller must still retain
actual execution evidence and the task's authority. The checker never executes a
renderer, installs an engine or proves that a self-authored receipt is authentic.

An engine probe can establish availability for the named task/capability when its
executable, interface, environment and permission remain current. It does not
qualify a later chart: the final artifact needs its own source-to-mark map, actual
open/render, native text/data editability, accessibility and scientific-meaning
checks bound to its final hashes. Keep missing gates pending. Do not fabricate
render output or promote a task observation to global host compatibility.
