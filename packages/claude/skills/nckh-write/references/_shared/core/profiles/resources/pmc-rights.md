# PMC article snapshot rights

> Owned package metadata: this file is an authored rights record and is not a
> verbatim copy of the upstream Creative Commons license.

The two packaged JSONL records are bounded normalizations of the pinned
Europe PMC JATS/XML responses. Each article XML contains an article-level
Creative Commons Attribution 4.0 statement. The CC BY 4.0 record permits
reuse with attribution; the article license statement and PMCID/DOI remain
part of each normalized record.

The reader preserves the article identity, license evidence, abstract and
bounded body excerpt. It does not treat PMC-wide open-access status as a
universal license. The original XML hashes are retained as explicit lineage;
the XML files remain in staging and are not packaged.
