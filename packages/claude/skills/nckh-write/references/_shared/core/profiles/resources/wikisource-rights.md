# Wikisource Vietnamese snapshot rights

> Owned package metadata: this file is an authored rights record and is not a
> verbatim copy of the upstream Creative Commons license.

The packaged JSONL is a normalized selection from three pinned Wikisource child
API and rendered-page responses. Each page footer identifies CC BY-SA 4.0 for
the Wikisource page text. The pages also state a public-domain rationale for
the underlying works. That rationale is retained as metadata, with the bounded
publication/rights review below for these identified old editions. Other
jurisdictions and later editions require their own review.

The artifact contains only records marked `actual_passage=true` as prose or
verse samples. Parent IDs remain in each child record for locator context.
Normalization removes markup and layout noise, preserves text and paragraph
boundaries, and does not silently correct spelling or transcription. Raw API
and HTML hashes are pinned as lineage in the resource registry; the raw files
remain in staging and are not packaged.
