# Scientific and native visual review proposal

Status: proposal; domain/native reviewer approval and thresholds are pending.
Record observations using [the rubric catalog](catalog.json).

## Criteria

- Each plotted value, label and mechanism arrow maps to data, source evidence or an explicit inference.
- Axes, scale, units, denominators, uncertainty and comparison framing retain scientific meaning.
- Mechanisms and illustrative artwork are labeled according to their actual evidence class.
- Typography, contrast, labeling, alt text and reading order are legible in the intended medium.
- The final source opens in the selected native application and contains the required editable objects.
- The render matches the same final source hash; visual inspection records defects and limitations.
- Asset provenance, permitted use and selected venue requirements are cleared for the intended output.

Review scientific truth, visual communication, rendering and native editability
separately. A raster preview does not prove editable source; file presence or a
successful export does not prove a render was inspected. Keep actual application,
version, object checks and render references in the receipt. Changed final files
invalidate affected QA. Missing engine, reviewer, rights or application evidence
leaves the corresponding gate pending.
