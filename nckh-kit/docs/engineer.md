# Engineer kit

Thirteen domains cover scout, debug, fix, test, code-review, security, context, docs,
frontend, backend, data, devops and git. Diagnose/review-only requests preserve product
bytes. Fix needs a proven cause and meaningful regression evidence. Data changes need
a backup before mutation; deployment/Git publication retain explicit target authority.

[nckh-xia](../skills/tooling/nckh-xia/SKILL.md) is separate tooling: compare reports;
port/improve plan. No implementation/install and no shadow of upstream ak-xia.
Framework/provider/upstream adapters are unavailable until selected and qualified.

Local deterministic checks are not production/provider/native acceptance.
No source body/code from paid AgentKit bundles is redistributed.

Scientific file curation and evaluation use the four Core owners in
[research and writing](research-and-writing.md#scientific-data-and-evaluation).
`nckh-data` keeps database/schema/migration responsibility. `nckh-devops` records
task-selected research environments and owned process cleanup; a frozen manifest
does not authorize cloud, cluster, provider or fault injection operations.
